Barcode Distance Test

Each row shows a QR Code, a PASCAL-MDS Standard code and a PASCAL-MDS Dense code of the same text at the same printed width. The tag in the text (a1, a2, …) tells which size was read.

  1. Show this page on a computer screen at 100% zoom, brightness high.
  2. Photograph each group with your phone's normal camera from several real distances: 0.5 m, 1 m, 1.5 m and 2 m, straight on, then a few at an angle. Normal room light helps.
  3. Upload the photos in the chat. Both codes in every photo get decoded and compared.
