Barcode Distance Test

Each row shows a QR Code and a PASCAL-MDS code of the same text at the same printed width. The tag in the text (a1, a2, …) tells which size was read.

  1. Show this page on a computer screen at 100% zoom, brightness high.
  2. Photograph it with your phone's normal camera from several distances (for example 30 cm, 60 cm, 1 m, 1.5 m), straight on, then a few at an angle.
  3. Upload the photos in the chat. Both codes in every photo get decoded and compared.
